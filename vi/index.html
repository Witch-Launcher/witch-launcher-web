PHIÊN BẢN & LOADER

Mọi phiên bản.
Mọi loader.

Từ những bản Beta sớm nhất tới snapshot mới nhất. Vanilla, Fabric, Quilt, Forge, NeoForge và OptiFine — mỗi thứ tách riêng trong profile của mình, với mod, world và pack riêng.

  • Beta_a1.2 → bản phát hành & snapshot mới nhất
  • Cài Fabric & Quilt ngay từ trình chọn phiên bản
  • Nhập file cài Forge / NeoForge
  • Instance tách biệt theo từng profile
MOD & NỘI DUNG

Modrinth & CurseForge,
ngay bên trong.

Trình duyệt nội dung, tự giải phụ thuộc và cài bằng một chạm cho mod, modpack, shader pack, resource pack và map phiêu lưu — không cần rời launcher.

  • Duyệt mod, pack & shader ngay trong ứng dụng
  • Tự động giải quyết phụ thuộc
  • Nhập modpack qua manifest.json của CurseForge
  • Theo từng profile: mod · shader · resource pack · world
SHADER & PACK

Đường ống shader
cho phép iOS.

Sodium + Iris trên renderer TGLMT, cache shader GLSL và upscaling FSR 1.0. Volumetric light và PBR chạy trên một chiếc điện thoại — êm thấm như bất cứ điều gì.

  • Mod shader Sodium + Iris trên TGLMT
  • Tinh chỉnh bộ cache shader theo từng renderer
  • Thu phóng FSR 1.0 & tỷ lệ phân giải
  • Frame Generation (MADI · camera reprojection)
RUNTIME & TÀI KHOẢN

Java 8 → 25.
Tải ngay trong app.

Tài khoản Microsoft, local, demo và Ely.by. Java 8 tới 25 tải vào máy bằng downloader đa luồng, LWJGL 3.3.3 → 3.4.1 chọn được theo profile.

  • Bộ quản lý runtime Java 8 / 17 / 21 / 25
  • Tải đa luồng, JVM args & RAM tuỳ chỉnh
  • Microsoft · local · demo · Ely.by
  • Tự cập nhật: kênh Auto / Beta / Stable
CÁ NHÂN HOÁ

Phong cách của bạn.

Giao diện, màu nhấn, blur, viền, app font và icon ứng dụng. Plugin .plgw có chữ ký có thể thêm JavaScript, module native và cả các bảng cài đặt riêng.

  • Theme · font · icon · blur · viền
  • 52 ngôn ngữ, có cả bộ ngôn ngữ RTL
  • Hệ plugin .plgw được ký số
  • StikJIT tích hợp trên iOS 17.4+
